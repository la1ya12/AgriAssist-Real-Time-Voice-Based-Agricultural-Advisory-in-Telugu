# AgriAssist-Real-Time-Voice-Based-Agricultural-Advisory-in-Telugu
AGRIASSIST is an AI-powered agricultural chatbot designed to assist farmers in Andhra Pradesh and Telangana by providing real-time, easy-to-understand information in Telugu. The system supports both voice and text interaction, making it accessible to users with limited literacy and digital skills.
🚀 Features
🎙️ Voice and text interaction in Telugu
🌾 Crop advisory and best farming practices
🌦️ Real-time weather updates
💰 Market price information
🐛 Pest and disease guidance
🏛️ Government schemes and subsidies info
🛠️ Technologies Used
Natural Language Processing (NLP)
Automatic Speech Recognition (ASR)
Text-to-Speech (TTS)
Python / FastAPI (backend)
Machine Learning for intent classification
🎯 Objective

To bridge the information gap for farmers by providing a simple, localized, and voice-enabled digital assistant.

🌍 Impact
Improves decision-making for farmers
Supports digital inclusion in rural areas
Aligns with Sustainable Development Goals (SDGs)
📌 Future Scope
Multi-language support
Offline functionality
Integration with IoT-based farm sensors
